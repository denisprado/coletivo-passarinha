# Coletivo Interdisciplinar Passarinha 🕊️🌿

Site oficial do **Coletivo Interdisciplinar Passarinha** (Arte • Educação • Ambiental), sediado no Ponto de Cultura Quintal Garatuja em Campinas/SP.

🌐 **Site no ar (Deploy Vercel):** [https://coletivo-passarinha.vercel.app](https://coletivo-passarinha.vercel.app)  
📦 **Repositório GitHub:** [https://github.com/denisprado/coletivo-passarinha](https://github.com/denisprado/coletivo-passarinha)

---

## 🎨 Conceito e Identidade Visual

O site foi estruturado com foco na acessibilidade, ludicidade e na identidade visual viva da Passarinha, utilizando um layout de **faixas horizontais marcantes (*color-blocking*)** inspirado na referência do coletivo:

- **Faixa 1 (Institucional):** Apresentação poética e manifesto do coletivo, com o logotipo oficial em aquarela em destaque.
- **Faixa 2 (Ponto de Cultura Quintal Garatuja):** História da sede física em Campinas/SP, ações formativas e comunitárias.
- **Faixa 3 (A História de Aru):** Os 12 princípios da Permacultura em cordel, com player interativo da trilha sonora e central de downloads de e-book e materiais didáticos.
- **Faixa 4 (Espetáculos Cênicos):** Catálogo de espetáculos (*Histórias da Passarinha, Plástico, Fora de Onde?, Show Nascente, Histórias do Bosque dos Guarantãs, Nosso Canto*).
- **Faixa 5 (Oficinas & Práticas Formativas):** *Ateliê Jogar Dentro*, *Ecobrinquedoteca Jogar Dentro* (PNAB 2025) e *Orquestra de Pandeiros* (pesquisa UNICAMP).
- **Faixa 6 (Audiovisual):** *A Caixa Mágica*, *Fora de Onde?* e *O Que se Passa no Formigueiro?*.
- **Faixa 7 / Rodapé:** Canais diretos de contato, WhatsApp da produção e redes sociais (`@coletivopassarinha`, `@quintalgaratuja`, `@aru.permacultura`).

## 🚀 Tecnologias Utilizadas

- **Next.js 16 (App Router)**
- **React 19**
- **Tailwind CSS v4**
- **Lucide Icons**
- **Vercel** para hospedagem e deploy contínuo

## 💻 Desenvolvimento Local

```bash
# Clone o repositório
git clone https://github.com/denisprado/coletivo-passarinha.git

# Acesse o diretório
cd coletivo-passarinha

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no seu navegador para ver o resultado.
